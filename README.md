# Lab 02 — Біти не брешуть: системи числення, прапорці й ALU

## Реалізовані інструкції
Згідно з [ISA.uk.md](ISA.uk.md), у цій лабораторній роботі реалізовано:
- Група `0x0_`: `HALT` (`0x00`), `NOP` (`0x01`)
- Група `0x1_`: `ADD` (`0x10`), `SUB` (`0x11`), `AND` (`0x12`), `OR` (`0x13`), `XOR` (`0x14`), `NOT` (`0x15`), `SHL` (`0x16`), `SHR` (`0x17`), `INC` (`0x18`), `DEC` (`0x19`)

## Приклади роботи ALU
1. **Додавання з перенесенням (Carry):**
   - Вхідні дані: `A = 200`, `B = 100`
   - Операція: `ADD` (`0x10`)
   - Результат: `A = 44`, Прапорці: `Z=0, N=0, C=1` 
   - *Пояснення:* $200 + 100 = 300$, що перевищує максимальне значення 8-біткового байта (255). Сталося переповнення ($300 - 256 = 44$), і процесор виставив прапорець перенесення `C`.

2. **Побітова операція AND:**
   - Вхідні дані: `A = 7` (`00000111`), `B = 1` (`00000001`)
   - Операція: `AND` (`0x12`)
   - Результат: `A = 1`, Прапорці: `Z=0, N=0, C=0`

## Трасування програми
Програма, завантажена через команду `set`:
- Адреса `0x00`: `0x10` (`ADD`)
- Адреса `0x01`: `0x00` (`HALT`)

Початкові регістри: `A = 200`, `B = 100`, `PC = 0x0`

- **Крок 1 (`step`):** Виконується `ADD` (`0x10`) з адреси `0x0`
  - Новий стан: `PC = 0x1`, `A = 44`, Прапорці `[ Z:0 N:0 C:1 ]`
- **Крок 2 (`step`):** Виконується `HALT` (`0x00`) з адреси `0x1`
  - Новий стан: `PC = 0x2`, процесор зупиняється (`[HALTED]`).
